## Inspirations
This session consolidates the foundational frameworks, technical skills, and design philosophies that drive the Agentic Enterprise architecture. These resources provide the "how" and "why" for building a high-performance, cost-efficient, and well-governed AI agent ecosystem.

- https://github.com/paperclipai/paperclip: The primary inspiration for high-level orchestration. It treats AI agents as a coordinated company rather than isolated tools, providing org charts, budgets, and governance.
- https://github.com/JuliusBrussee/caveman: A suite for extreme efficiency. It includes caveman (token saving), cavemem (persistent memory), and cavekit (autonomous build loops), helping agents do more with 75% fewer tokens.
- https://github.com/sickn33/antigravity-awesome-skills: A massive, installable library of over 1,445 agentic skills. It serves as the primary catalog for injecting technical capabilities into agents at runtime.
- https://github.com/Gitlawb/openclaude: Use OpenAI-compatible APIs, Gemini, GitHub Models, Codex OAuth, Codex, Ollama, Atomic Chat, and other supported backends while keeping one terminal-first workflow: prompts, tools, agents, MCP, slash commands, and streaming output.
